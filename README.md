# Meu Gestor de Negócios V8.2.2 — Android

Projecto Android WebView offline baseado no HTML V8.2.2 recuperado do histórico.

## Gerar APK pelo GitHub no telemóvel
1. Extraia este ZIP.
2. Envie todos os ficheiros e pastas para a raiz do repositório GitHub `domsalva22-hub/meugestordenegociosV8`, branch `main`, mantendo a estrutura.
3. Abra **Actions** e seleccione **Gerar APK - Meu Gestor V8.2.2**.
4. Toque em **Run workflow** (ou aguarde a compilação após o push).
5. Quando terminar com sucesso, abra a execução e descarregue o artefacto `Meu-Gestor-de-Negocios-V8.2.2-APK`.
6. Extraia o artefacto e instale `app-debug.apk` no Android.

A aplicação usa armazenamento local do WebView. Faça cópias de segurança na área Configurações > Cópias de segurança. Os dados existentes no navegador/PWA não são importados automaticamente para a instalação Android; use a função Restaurar cópia se tiver um JSON exportado.
